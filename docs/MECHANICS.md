# Механика и учебные образцы

## Оценка

После согласования с пользователем активная шкала стала плавной: `score = max(0, 100 − RMS)`, где RMS — среднеквадратичное смещение только подвижных букв относительно образца. Во всех гарнитурах высота прописной буквы равна 160 координатным единицам, поэтому размер экрана не влияет на оценку. Смещение одной подвижной буквы на 1, 2 или 5 единиц даёт 99%, 98% и 95%. Клиент округляет расчёт до шести знаков, интерфейс — до целого. Критерий зачёта применяется к показанному проценту.

Исходная функция Kern Type сохранена как `legacyScore` для воспроизводимости. Её скачок с 100% ниже 85% мешал использовать выбранный диапазон 95–100%; она больше не используется для новых попыток.

Подпись «Точное совпадение» требует совпадения координат. Если очень малое смещение округляется до 100%, это отмечается как результат с учётом округления. В общий итог входит первая успешная попытка каждого упражнения; ошибка при повторе не отменяет достижение. Прежние результаты серии с тремя повторениями сохраняются.

## Эталоны и шрифты

Эталоны — рабочие образцы на основе штатного кернинга каждого шрифта и небольших авторских коррекций. Они не утверждены академией. Перед учебным применением рекомендуется их проверка преподавателем. Редактируются в `scripts/prepare_fonts.py`, массив `SPECS`.

Файлы шрифтов получены из открытого репозитория Google Fonts. В `dist/fonts/` находятся лицензии SIL Open Font License, оригинальные файлы и манифест с источниками и SHA-256. Тренажёр использует только русские кириллические слова, несмотря на наличие других алфавитов в исходных гарнитурах.

Оригинальные имена гарнитур сохраняются во всех подписях и списках: PT Sans, PT Serif, Golos Text и Literata. В справке используются оригинальные названия ParaType, TypeTogether, Google Fonts, GitHub, Kern Type и Method of Action со ссылками на источники. Это исключение для имён собственных; учебные слова и остальные подписи остаются на русском языке.

Для повторной генерации: `python -m pip install --target .tools/python uharfbuzz fonttools`, затем `python scripts/prepare_fonts.py`. Форма кириллических глифов получена HarfBuzz с языком `ru` и письмом `Cyrl`. Параметры вариативных шрифтов зафиксированы в спецификации.

Для повторного использования уже включённых файлов без скачивания: `python scripts/prepare_fonts.py --offline`. Словарь для собственных слов: `python scripts/prepare_alphabet.py`. Он включает весь русский алфавит в обоих регистрах, Ё/ё и парное позиционирование. Полученные позиции проверяются против полного шейпинга HarfBuzz на контрольных словах.

Лицензии конкретных включённых файлов — SIL Open Font License 1.1. Она разрешает бесплатное использование на веб-сайтах, встраивание и распространение вместе с приложением при сохранении лицензии и уведомлений об авторских правах. Оригинальные файлы и лицензии сохранены, платные версии ПТ Санс Про и ПТ Сериф Про не используются. Проверены официальный текст https://openfontlicense.org/ и публикация Паратайп https://info.paratype.ru/shriftovaya-sistema-pt-sans-pt-serif-i-pt-mono/ .

## Проверки

`npm install`, затем `npm test`. Проверки охватывают граничные значения исходной формулы, завершение с 0%, кириллицу, доступность эталонов в пределах движения и целостность восемнадцати заданий. Браузерные проверки описаны в `QA.md`.

Оформление переработано по AI Design Skills и Redesign Existing Projects от elayadesign. Интерфейс использует локальный Manrope (SIL OFL 1.1), нейтральный угольный фон и единый набор размеров текста и отступов. Учебные гарнитуры остаются отдельными. Процент расположен в центре фиксированной нижней полосы; проверка не меняет размер слова.
